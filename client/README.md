# FarmSync

FarmSync is a MERN application for creating crop cycles, checking current mandi prices,
planning around weather, estimating current revenue, predicting crop disease, and tracking
actual expenses and sales.

## Development

Run the backend from `server/` and the Vite client from `client/`. The backend expects
MongoDB and the environment variables documented in the project PRD.

The client uses React, Vite, Tailwind CSS, React Router, and Recharts.
